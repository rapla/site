---
title: What's coming in Rapla 3
description: A web app, a GraphQL API and a modern server — alpha planned for October 2026.
---

Rapla 3 is in development. It keeps everything Rapla 2 users rely on — resource and event types, permissions, conflict detection, the desktop client — and rebuilds the platform around it.

**Try it early:** nightly builds of the development branch are on the [download page](/download.html#rapla-3-nightly). They are untested and not for production.
